🌷 About Echologic

Echologic is an ESP32-based AI assistant prototype built using the Xiaozhi AI ecosystem.

It combines embedded hardware, wireless connectivity, and cloud-based artificial intelligence to create a compact interactive assistant.

Think of it as a tiny electronic companion that connects the physical world with the intelligence of AI. 💕

💻 The Tech Behind the Magic

Technology| Purpose
ESP32| Main microcontroller
Xiaozhi AI| AI assistant ecosystem
Wi-Fi| Wireless connectivity
OLED Display| Visual interface
I2C| Display communication
Embedded C/C++| Firmware environment, where applicable
